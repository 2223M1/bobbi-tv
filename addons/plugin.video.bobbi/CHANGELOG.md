# 波比 TV 版本说明

## 0.1.106 · 自动更新稳健性与片库连播体验打磨

- 自动更新更守规矩：严格在遥控器无操作满 20 秒后再静默下载与安装，升级后更稳妥地切回影院界面。
- 片库浏览与剧集连播更顺畅：修复 Emby 深层页码跳转与超长列表提示点击无响应的问题，长篇剧集自动连播定位更准更快。
- 右上角消息提示更清爽：静默屏蔽遥控器重连提示的同时，不再卡住后续正常的系统提醒。

## 0.1.105 · 实机双端同步推送与空闲无感自动升级正式定版

### 双端同步推送与无感更新闭环
- **GitCode 国内直连源 + GitHub 双端实时同步定版**：全量校验稳定版更新流、签名完整包与启动器入口包，确保国内与海外设备均可第一时间收到正式版更新推送。
- **CoreELEC 空闲全自动无感升级实机定版**：设备在非播放空闲状态下自动完成线上签名包发现、下载、组件原子切换、启动器同步及影院皮肤无感恢复，同时支持在设置中一键检查更新或禁止自动更新。

## 0.1.104 · 空闲自动更新文件锁探测修复与唤醒提速

### 自动更新稳定性修复
- **非阻塞文件锁租约探测**：修正 CoreELEC 已安装设备上常驻 `installation.lock` 锁节点导致后台自动更新持续延后的问题，改用非阻塞 `flock` 实时探测真实安装互斥锁状态。
- **屏幕保护唤醒后快速复检**：设备从休眠/屏保唤醒且满足 20 秒空闲阈值后，25 秒内自动复检线上版本推送并静默完成后台升级。

## 0.1.103 · 双镜像通道与启动器离线自愈增强

### 更新连续性与国内直连自愈
- **旧版升新版启动器离线自愈**：从早期版本（`<= CE2190`）在线更新至新版后，后台服务启动时自动从本机已验签的 `recovery-v1` 离线恢复包补齐最新 `script.bobbi.start` 启动器及引导层，即使在无法直连 GitHub Raw 的国内网络环境下也可无缝衔后续空闲全自动更新。
- **GitCode 与 GitHub 双镜像全量校验闭环**：每次正式版发布均同步完成 GitCode 国内直连镜像与 GitHub 双端签名资产、稳定版订阅源及字节级回读核验。

## 0.1.102 · 双镜像同步推送与默认空闲自动更新

### 自动更新与设置开关
- **GitCode 与 GitHub 双镜像实时同步推送**：正式版在线更新流与签名安装包同步推送至国内直连镜像（GitCode）与 GitHub，确保国内外网络环境均可实时发现并高速拉取最新版本。
- **默认开启空闲全自动更新**：当设备处于空闲状态且未在播放影片时，后台自动发现新版本并完成签名校验、组件切换、启动器同步与界面恢复，不中断正常观影。
- **新增「立即检查更新」与「禁止自动更新」设置项**：在设置主页「系统维护」及「影院设置 · 更新与恢复」提供一键检查更新入口与自动更新开关（默认自动更新，可随时切换为禁止自动更新、仅手动检查）。

## 0.1.101 · 超大媒体库浏览与遥控流畅度优化

- 长篇剧集与大目录浏览优化：突破 Emby 同季自动连播 200 集限制，升级 Plex 剧集库按「剧集 → 季 → 单集」分级读取，并在 Emby 深层目录提供「跳转到指定页」与上限提示。
- 首页加载与海报读取优化：为首页 Emby 栏目设置单栏总耗时上限以隔离慢响应源，并在后台图像服务内短期复用已核验的海报标签。
- 遥控与播放体验优化：过滤遥控器空闲重连弹窗并与音量条、进度条互不遮挡，精简首页导航判断逻辑并减少播放期间的高频日志写入。

## 0.1.100 · CoreELEC / Kodi 检索源热修与体验增强

### 检索源与自定义 Torznab 增强
- **自定义 Torznab 共享受限传输与及时释放租约**：自定义 Torznab 检索统一走受限流式 HTTP 通道（`fetch_independent`）并绑定当前配置槽位，支持在慢滴流响应下按取消信号或总截止时间立即退出并释放检索租约，不再阻塞下一次搜索。
- **恢复默认源同步恢复启用状态**：在检索源管理中心执行“恢复全部默认源”时，自动为此前通过管理菜单移除的默认源写回启用开关，同时完整保留既有地址/API Key 及用户原本单独关闭但未移除的其他源状态。
- **自定义源直达地址兼容、多语别名并发检索与一键连接测试**：自动兼容从 Jackett 网页复制的 `/results/torznab/` 地址并规整为直达 `/api` 端点；支持携带中/英/原名最多 3 个别名并发检索并按哈希去重；在自定义 Torznab 编辑菜单新增“测试此自定义源连接”快捷检测。

## 0.1.99 · CoreELEC / Kodi 整合版

### 中英双语本地化、六分类设置与自定义导航空间
- 支持简体中文与英文界面完整切换（含主机官方中文语言包校验安装、皮肤全窗口、主插件与伴生组件、手机扫码管理页、Android 助手与 Windows 启动器），界面语言独立于影视元数据及音轨字幕语言偏好。
- 重组设置主页与主插件设置为六大清晰分类（界面与语言、首页与导航、播放与字幕、内容与来源偏好、网络与设备、系统维护），保留全部既有配置项与旧路由兼容。
- 侧栏与顶栏升级为编译期静态生成的 13 项导航空间（首页固定首位，其余 12 项可自由增减与排序），并提供常驻“工具与电源”按钮、主页导航短按返回键呼出控制中心、能力门控的关机/重启/退出确认以及只读显示链路与电视点对点（Just Scan）过扫描排查说明。

### 账号与来源中心（四域收敛）
- 新增统一入口 `RunScript(script.bobbi.setup,accounts)`，收敛为用户服务、媒体服务器、网盘与共享来源、设备与手机四个清晰域，同时保留原有网盘与片库快捷入口。
- 修正多层管理菜单的导航返回状态：从“我的片库”或“账号与来源中心”进入媒体服务器浏览后直接打开目标片库目录，不再重复弹出外层管理菜单或触发多余的列表刷新。
- 打开“设备与手机”菜单仅读取本机配对状态，不会自动开启局域网端口或创建手机管理会话；所有手机扫码管理均需在电视端明确确认，关闭二维码窗口即刻撤销。

### 媒体服务器与在途播放连续性
- **Emby 支持保存多个服务器/用户连接并显式切换“当前浏览账号”**；切换首页与默认片库的当前浏览账号不会中断已在播放的 Emby 会话（含动态海报片库及已有个人作品索引），播放进度、暂停、拖动与停止状态仍准确回写至原播放账号。
- 修改服务器密码或访问令牌、移除服务器连接、退出登录或切换 Kodi 用户配置时，仍立即撤销对应流读取与播放控制权限。
- **Jellyfin 与 Plex 当前仍保持每类单连接**，尚未开放同类型多账号浏览切换。
- 片库根目录新增受限 `kind=media_server` 视图，仅枚举已登记的媒体服务器并提供管理入口；浏览指定服务器不会隐式更改默认浏览账号。

### 缓存清理、备份与重置边界
- 清理 Stremio 缓存与全局缓存仅删除可重建的临时目录、片源查询与元数据缓存，完整保留人工添加与账号导入的 Stremio / Nuvio 来源定义、同清单多地址配置、播放/目录/直播用途选择及自定义别名。
- 插件偏好备份仅包含本插件配置与可选自定义 Stremio 来源（受敏感信息剥离选项控制），人工片库描述按当前 Kodi 用户与网盘账号范围独立导出导入，不包含媒体服务器或 115 账号凭据。
- 重置本插件偏好与清除本插件数据均需独立二次确认；清除本地浏览与文件历史仅清理插件历史记录，不影响云端文件或服务器媒体。

### 液态玻璃（Liquid Glass）与更新提醒
- 经典界面与液态玻璃用户偏好同实时渲染运行状态分离：**实时光学折射仅在通过资格校验的 CoreELEC 宿主环境且完成整包安装/迁移并重启 Kodi 后启用**；未满足条件或待重启时安全回退静态材质，不影响正常选片与播放。
- 本页展示当前已安装版本的本地离线说明；在线新版本检查与整包恢复请前往“影院设置 · 更新与恢复”。首次升级时若旧版显式设置了关闭更新提醒，将自动做一次性兼容迁移，后续统一由“新版本提醒”两态开关管理。
