# CE2021 后续验收矩阵

## 状态词

- PASS：针对明确对象取得符合预期的证据。
- FAIL：执行到目标场景且实际行为不符合预期。
- BLOCKED：缺少输入、权限或环境，尚未测试到目标行为。
- NOT_RUN：本轮没有执行。
- HISTORICAL：历史不同源码或不同安装包的结果。

不要将工具进程正常退出、传输成功、pending或不适配的夹具当作PASS。

## 最小关闭顺序

1. 先关闭源码、构建、真实包对应关系中的P1问题。
2. 同代入口完成安装/维护恢复和回退验证。
3. 修复报告链接并形成可访问的证据索引。
4. 根据用户观看需求处理BT与中文字幕；清楚区分资源不可用和客户端故障。
5. 按实际结果决定候选可用范围，不用历史通过数替代当前结论。
