# 更新边界

更新通道仍未启用。本地正在实现并测试下述合同，不能视为实机验收。

1. 发布者离线生成 RSA-3072 密钥；客户端固定公钥，对原始 manifest
   字节验证 SHA-256 签名，不从下载响应取得新的信任公钥。
2. 所有成组组件有固定 ID、版本、大小和 SHA-256。清单必须和当前
   配置的完整组件集合一致，平台/通道/递增序号必须匹配。
3. 下载、解压、静态检查全部完成后，仍需重新检查闲时并取得提交租约。
   Kodi 适配器尚未完成租约联调，不能仅凭“没有播放”就覆盖运行代码。
4. 更新仅修改已批准的 bobbi 插件目录。userdata、其他插件、固件、
   Kodi 原生程序、云盘账号及 Android APK 都不在事务内。
5. 提交有持久日志和备份；失败或下次启动发现未完成事务时先恢复。
   未恢复成功前不能宣称组件就绪。文件操作不是整个目录组的原子提交。
6. 标准 Kodi 的插件注册、已加载 Python 解释器、活动皮肤刷新要另行
   验收；代码复制成功不代表 Kodi 已成功使用新版本。
7. 完整实现后每日检查，播放/选源/关键后台任务期间延后。
   APK 通过 Android 安装确认更新；不兼容迁移只提示，不静默安装。

测试密钥只在测试内存中临时生成，不是发行签名密钥。当前尚无
正式签名密钥/信任根，也没有发布可自动升级的清单。
