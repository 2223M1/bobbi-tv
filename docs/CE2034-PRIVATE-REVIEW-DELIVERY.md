## 海报：根因、变化和实际证据

旧服务最多接收 4 个 HTTP 请求，4 张慢图占用时，已缓存的第 5 张也被断开。
另有每次启动更换 URL 的缓存键抖动，以及可选 Fanart 失败字典被当成成功缓存
24 小时。旧纹理数据库中数十个历史端口留下记录，不能误解成当前所有 URL 都失效。

现在是 32 个有界 HTTP handler、6 个实际上游缺图下载者，热图直接返回、同图
合并、第 7 个独立缺图排队；真正满载明确 503/Retry-After。公共图片端口/token
正常重启保持稳定，旧本机图片 URL 仅按严格公共 TMDb 语法重绑。TLS 验证成功
的官方 DoH 路线在 DNS TTL 内复用，失败撤销，不绕过证书/主机名验证。
Fanart 失败不当成功缓存，后续可重试。未删除用户纹理库或旧图片缓存。
