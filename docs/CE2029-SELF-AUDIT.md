### 安装预检的精确范围

预检拒绝“检查时已播放”的操作，保持原完成 journal 不变。预检与文件切换之间仍可能
发生新的并发播放，因此原 quiesce 的前后检查、失败恢复和 OS lease 不删不放宽。
这不是对 Kodi 全局播放的加锁或冻结，也不宣称消除了所有并发时序。

### 账号固定的精确范围

已有选择携带的 `_account` 优先；初次捕获失败保留未知状态，不能在后续重试中偷偷
借用新登录账号。旧云侧任务因此失去准入，但独立 BT/公共 HTTP 的播放不被停止。
正常同用户换凭据而 account_id/epoch 不变时继续使用，避免把续期当换号。
