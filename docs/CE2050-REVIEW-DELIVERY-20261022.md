## 三项产品修复

| 类别 | CE2049 可复现行为 | CE2050 行为与验证 |
| --- | --- | --- |
| 可选元数据预算 | 远端成功/撤销/身份变化之后，200 ms SQLite 写入超时将原结果覆盖成 deadline | 仅在可选 Cache 写入边界隔离本地 deadline；保留远端值/原错误及错误码，不重发 API。原独立临时 SQLite 探针由 3 例失败变为 12/12 通过（含旧版本对照）。 |
| 建连预算与 Back | localhost 两个地址重复花费 timeout，本机原始观察总耗时 4.047 s，Back 等待 3.969 s | 请求自有非阻塞 socket 在建连前注册，所有地址共享截止时间，未用时间可留给后续地址；保留完整 join。最终反例收据见 after-final，返回时 0 worker。 |
| 搜索中换号 | QQdocs 使用查询开始时 A 的 scope；Juku 的 B 空状态不能清掉 session 的 A 失败 | 发布时读当前代际，携带精确 tuple、scope 指纹和有序观察；新的空状态能清旧失败，迟到空值/失败不能反写，注销同样处理。稳定卡键、焦点、手动重试和 BT 卡保留。 |

新增状态只控制展示和推荐，不是播放授权。账号、取消和绑定检查仍由原 AccountManager/ShareStream 执行。实际 Binding 与可选写入交错测试覆盖取消、切号、注销、同账号续期；前三者不交付旧地址，续期正常返回。

网络专项使用发行的 Requests 2.31.0 / urllib3 2.2.3 和真实回环 socket，覆盖 IPv4、IPv6、localhost 仅 IPv4 监听回退、无 Back 的总截止时间、可信 TLS、拒绝不可信证书和主机名不符、重复请求。未关闭证书校验、未全局改 urllib3 或新建无法 join 的 DNS 线程。同步 getaddrinfo 的 OS 阻塞边界仍明确保留。

## 实机观察与未解决事项

### 原失败源《心灵驿站》

在升级前 CE2049 对原 NTb 1080p 源复查：hash `e1317fd62599094606d2efb69c65aed00fc06c0c`，文件 9,317,886,824 字节，没有换版或降码率。此次未进入 AV，而是 120.467 秒预缓冲超时；原始启动总轨迹约 124.759 秒。

停播前同期状态：2 个活跃 peer，约 82–98 KB/s，预缓冲目标 32,212,254 字节，现场三次读数从约 3.96 MB 到 12.60 MB；产品超时回执中的最近一次计数为 7,733,248 字节。采样时刻不同，不强行拼成同一瞬间。查询 status 可能续租，本轮明确记录这种观察干预，没有靠停止后的 404 推断原因。

这支持**本次下载供给不足、尚未进入原生解码**，不能证明上轮第 36 秒卡住的唯一根因；原问题保持开放。没有同版 115 就绪证据，不伪造交接通过，不增加 add/preload 重试，不延长所有超时或永久拉黑作品。

### 新电影《史崔特先生的故事》

TMDb 404 / 1999，普通搜索手选 115 `The.Straight.Story.1999.1080p.BluRay.x264.DTS-FGT.mkv`。约 7.787 秒首次观察 AV，1920×816 H264、英文 DTS 5.1、外挂中文应用回执。

启动采样 **未通过**：播放时钟停驻约 3.972 秒，但解码计数仍在推进，caching 采样未置 true；不能直接把它描述为画面确实停住，也不能删掉失败。后续 30.364 秒观察推进 30.280 秒、无采样缓存、解码掉帧/错误为 0，仅这个有限窗口通过。字幕平面截图未捕捉可见对白，不能认证字形/裁切/同步。

### 新动画《红辣椒》

TMDb 4977 / 2006，普通搜索手选 VCB-Studio BT，hash `43689968ea4877c489939bd11ae17bf534bf0f62`。约 35.765 秒首次观察 AV，1920×1080 HEVC、日语 FLAC 5.1，未转码或更换版本。启动捕获仅有约 3.523 秒连续正时钟 AV 样本，该小窗口通过，不夸大为整个启动或渲染连续性认证。
