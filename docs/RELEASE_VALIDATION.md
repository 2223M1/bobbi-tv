## 已知设计边界

标准 Kodi 播放只发送一次请求，没有伪造“已实播”收据；回执不明不重试。公开版不启动私人 native owner、CD2 任务或云转存服务。自定义成组更新引擎没有接入运行时，使用 Kodi 原生仓库并建议用户停止播放后更新。

Android HTTP 检索使用串行有界 socket 请求，不要求额外 Python 可执行文件。超时 / 取消不会把部分结果标为完整；DNS 与底层 socket 的协作式等待不冒称硬实时截止。
