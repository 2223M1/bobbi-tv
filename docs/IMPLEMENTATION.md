## 当前已知门槛

现有播放链依赖自定义 `Player.Bobi*` JSON-RPC 及 POSIX IPC；
普通 Kodi 不具备这些能力，不可只重命名插件即宣布兼容。
现有七个审查 ZIP 也不包含全部后台和原生依赖。
上游 Jacktook 许可声明存在冲突，需形成可追溯的处理结果；皮肤素材
与字体独立许可必须保留，不可整体改称 MIT。

用户当前不方便在电视旁操作：本轮只做本地 APK 与组件集成，不切换 AM6B 系统。
已只读确认 AM6B 当前从 SD 卡运行 CE、内置盘保留 Android 分区；尚未验证 Android 启动。
Z9X 8K 联通和实测延后，不阻塞通用 Android 开发，也不宣称其已通过认证。

个人来源已完成第一阶段：多连接管理、SMB/NFS/WebDAV/Kodi VFS、本机目录与直链片库导入，
使用同一标准播放交接并接入新“我的”入口；详见 [NAS 与网盘接入](LIBRARIES.md)。
当前属于已离线验证的组件预览，真实 NAS / Android 访问及播放尚待验收，
不据此勾选完整一键安装或全平台实播门禁。
