# 安装、登录与更新

本页对应 `0.1.0-alpha.1`，不是尚未实施的产品计划。需 Kodi 21 / Python 3.0.1；Android 8+ ARM32 或 ARM64。无需选择盒子型号。

## CoreELEC

1. 从 GitHub Release 下载 `repository.bobbi-0.1.0.zip` 放在 U 盘或可访问目录。
2. Kodi → 插件 → 从 ZIP 文件安装。Kodi 若要求允许第三方 ZIP，阅读提示后自行确认；无需改系统 SSH、Samba、防火墙或代理。
3. 从库安装 → bobbi TV → 程序插件 → **bobbi 开始使用**。由 Kodi 自动解析所有依赖。
4. 打开向导：自己的 115 / NAS / 片库均可跳过；BT 需要选择「连接本机助手 → CoreELEC 安装本机后台」。下载约 63 MB，版本 MatriX.147、SHA-256 固定。
5. 需要海报与影视搜索时配置自己的 TMDb API Key，最后选择「进入波比影院」。Kodi 弹出保留皮肤确认；不确认会恢复旧皮肤。

后台仅使用独立 profile、127.0.0.1:8090 与随机控制凭据。不覆盖 CD2、Yatse、其他 TorrServer 或系统服务；端口已被占用会停止，不杀旧进程。BT 协议自身需要对外连接网络，不等于开放远程控制。停止 Kodi 会终止本次服务自己启动的进程。

## Android

1. 安装 Release APK，打开「bobbi TV · 安装与后台」。如没有 Kodi，通过 APK 提示去 Kodi 官方下载页安装 Kodi 21。APK 不包含 Kodi，也不是原生独立影院播放器。
2. 「安装影院」保存 `repository.bobbi.zip` 到 Downloads，在 Kodi 按上面步骤安装仓库与「bobbi 开始使用」。若电视没有系统文件选择器，直接从 Release 下载仓库 ZIP 到 U 盘。
3. 使用 BT 时返回助手「启动本机后台」，等状态运行中，再「显示六位配对码」。
4. Kodi 向导 → 连接本机助手 → 输入配对码。两分钟内有效，只能用一次；成功后不用每次配对。不要把配对文件或二维码发给其他人。
5. 开始看片前启动助手后台，结束后可在通知中停止。助手不擅自开机自启；系统可能因省电策略停掉后台，需要你在系统设置允许相应行为。

APK 与插件沿用同一影院视觉语言；用户数据留在各自应用私有目录。不会尝试绕过 Android 沙箱直接修改 Kodi 的应用目录。无需 root 或 ADB。

## 登录自己的内容

- **115 分享读取**：向导 → 115 账号，用自己的「115生活」扫码并确认 Linux 客户端授权。仅成功后替换本机登录，取消 / 失败保留旧值。不会批量转存，也不读取其他人的登录态。
- **网盘与 NAS**：向导 → 我的网盘 / NAS / 片库，支持多个 SMB、NFS、WebDAV、本地目录及自有直链 JSON。详情见 [LIBRARIES.md](LIBRARIES.md)。
- **海报搜索**：到 themoviedb.org 的个人设置申请 API Key，在向导内隐藏输入；不是 API Read Access Token。网络无法访问 TMDb 时，NAS 和直链片库仍可用。
- **字幕 / 音轨**：向导可打开 Kodi 播放器语言设置，选择原始语言与中文偏好。播放中可以在音轨 / 字幕快捷菜单手动切换、关闭和调延迟；本版不保证自动找到外部字幕。

## 更新与恢复

Kodi 自带仓库负责版本检查和安装。建议选择「通知，但不要安装更新」，停止播放后再更新。APK 新版从同一个 Release 页面下载，系统确认后覆盖安装；同一长期签名保留账号与配置。

没有启用自定义 `UpdateEngine` 热替换逻辑：没有真实独占 Kodi 生命周期就不承诺整组原子更新。该引擎仍保留为单测覆盖的开发代码，不在正常安装路径运行。

回退：切回 Estuary → 退出 Kodi → 备份 Kodi userdata → 使用旧 Release 的 `bobbi-kodi-components-*.zip` 解开后逐项安装其中相同版本组件。正常安装不需要这份维护包。若 Kodi 禁止降级或依赖版本不一致，应恢复你自己的退出状态备份；不要删账号配置、不要混装私人 AM6B 更新包。APK 降级可能被 Android 拒绝，不承诺无数据降级。

## 验收边界

目前没有 Android 实机全新安装、HDR / Dolby Vision、直通、长时间播放或 Kodi 更新回退认证。先在可恢复环境试用，不刷机、不切换原 CE。后续实播应选从未测试过的新电影与动漫，记录作品、版本、字幕和音轨，不以搜索结果代替可播证明。
