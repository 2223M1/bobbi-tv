# 本轮新作品验收身份与边界

1903 首轮 CE 使用《荒蛮故事》(2014 / TMDb 265195) 和《少女终末旅行》
(2017 / TMDb 74185 / S01E01)。二者此前检索不到旧实播记录，本轮原始操作、
失败和成功证据均保留在 `review-evidence/ce-new-work-*`，不删除失败尝试。

- 《荒蛮故事》：普通选源等待 35 秒不自动播放；手选 115 2160p 原文件，
  6.96 秒观测到 AV，3840×1608 HEVC、西班牙语 EAC3 5.1、全屏。40 秒启动追踪
  和独立 30 秒观测无采样异常，硬解无掉帧/错误；**未取得中文字幕**。
  实际找到的 Assrt 候选 693678 在官方文件下载重定向链收到 HTTP 493。
  这是部分验收失败，不按“播放成功”抹去字幕缺失。
- 《少女终末旅行》：普通选源等待 35 秒不自动播放；手选 115 BDRemux 原文件，
  23.05 秒观测到 AV，1920×1080 AVC、日语 LPCM、UHA-WINGS-SC 中文字幕、全屏。
  启动/独立 30 秒观测通过，观测时没有掉帧/硬解错误。这是遥测，不是人工画质确认。
  后续持续观察至 1420.162 / 1422.005 秒，仍同实例、日语/中文字幕、前台，用户意图为 0。
  结束后回到首页且没有 S01E02。日志出现 demuxer ran dry，未捕获原生终态 reason，
  因此**不能认证自然 EOF 或续播通过**，也没有证明用户收到手选下一集提示。
  `RELEASE_ENVELOPE_UNPROVEN` 表明当前 BDRemux 命名（1920x1080、括号）未通过
  严格同版证明；本轮不靠放松身份条件自动换版。证据见
  `review-evidence/ce-natural-girls-last-tour-20261019.json` 及其 end/terminal 日志。

当前信息不足时，并非所有终态都有独立手选下一集弹窗：确认自然 EOF 且仍拥有请求时
会提示返回选源；错误或未知终态可能清理后回首页，需要从原作品季集页选择。
该体验缺口保留为待整改，不用已有季集入口冒充自动交接已完成。

两次检索都暴露 BT 收到成功响应但被网络总截止抹掉的缺陷，实际修复另行记录。
第一轮字幕路径为真实 `ce-f9` ABI；本地其他版本字幕复用路径遗漏也单独修复。
不将来源文件名中的“双语”或一个字幕候选当作已显示字幕。

## 最终候选的新作品

后续同文件重播只作缺陷回归，不计新作品覆盖。已再检索旧工作区的 docs、audit、
handoffs、implementation 及新 UI 的完整 review-evidence：

- 《燃烧》(Burning, 韩国 2018) 和《轻拍翻转小魔女》(Flip Flappers, 2016)
  没有找到旧实播记录；“花样年华”仅出现在第三方目录摘要，尚未作为选定测试作品。

`ce-final-fresh-work-identities.json` 保存 HTTPS 直连身份核验。选定《燃烧》为
TMDb **491584**、韩语 `버닝`，不能混入同年印度电影 TMDb 813106。
《轻拍翻转小魔女》为 TMDb **68272**，日语 `フリップフラッパーズ`，S01E01。
1905 已实际验证，结果不能合并成“全部通过”：

- 《燃烧》：14 个最终选源卡片，35 秒没有自动播放。手选
  `燃烧.Beoning.2018.BD1080P.x265.10bit.DTS-MTRen.mp4`（115），8.18 秒观测到 AV。
  1920×1080 HEVC、DTS-HD MA 5.1、全屏；启动追踪及独立 30 秒观测无异常。
  音轨标签为 `und`，不能从片名代替听音验收韩语；字幕列表为空且 Assrt 641764
  下载返回 493，不能认定已加载中文字幕，也不能仅据列表排除画面硬字幕。
  约 188 秒由精确实例停止，终态日志为 `STOP`。
- 《轻拍翻转小魔女》：9 个卡片，35 秒没有自动播放。手选 SweetSub & LoliHouse
  S01E01 所在 01–13 合集，未进入原生播放。旧 JackTorr 仍读取旧会话属性和旧
  IPC 路径，新父级已经改用波比 owner；旧子级马上判定 `superseded`，父级却
  收不到失败而等待。这是移植遗漏，不是已证实的做种速度问题。
  首次失败保留，后续同片源测试只计修复回归。

Windows 新作品另含《一次别离》(2011) 与《电脑线圈》(2007 / S01E01)。
前者暴露前台交接问题，并有失败及修正后回归；后者真实 115 BDRemux 为 1080p
H264/D3D11VA、日语 DTS-HD MA 5.1、喵萌奶茶屋繁中，全屏 30 秒观测无停顿。
《电脑线圈》冷启动约 54 秒，ASS 初始化与 partial-file 重连同时发生，不能全归因
字体，也不能声称 40 秒启动门槛通过。带测试覆盖文件的回执明确列出 overlay，
不能冒充冻结发行包验收。

工具只读记录 `not_tested`，不以无守卫全局操作替代。此限制不等于用户 UI 按钮不能用，
也不代表对应功能已经实机验收。
