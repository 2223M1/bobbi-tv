# AI 语音助手

CoreELEC / Kodi 遥控语音助手。语音转文字、智能体和语音合成独立配置，均可关闭；新安装默认关闭，先绑定语音按键，再扫码配置。


| 类别 | 可以这样说 |
|---|---|
| 播放电影 | “播放阿拉丁”“我要看爱你西蒙” |
| 播放电视剧 | “播放电视剧十八岁的天空”“继续看十八岁的天空” |
| 继续最近观看 | “继续看电影”“继续看电视剧”“继续看电视” |
| 从头播放 | “从头播放阿拉丁”“重新播放阿拉丁”“再看一遍阿拉丁”；单说“从头播放”作用于当前影片 |
| 直播频道 | “我要看CCTV1”“播放央视一套”“播放频道湖南卫视” |
| 播放控制 | “暂停”“继续播放”“停止播放”“上一项”“下一项” |
| 快进、后退 | “快进三十秒”“后退一分半”“快退两分钟” |
| 音量 | “音量调到三十”“音量提高十”“音量降低二十”“声音大一点”“声音小一点” |
| 静音 | “静音”“取消静音”“关闭声音”“恢复声音” |
| 字幕开关 | “打开字幕”“关闭字幕”“显示字幕”“隐藏字幕” |
| 打开页面 | “返回主页”“打开电影库”“打开电视剧库”“打开直播电视”“打开收藏夹”“打开设置”“全屏播放” |
| 打开插件 | “打开红果短剧”“打开筛选”“打开筛选页”“打开筛选插件”“打开遥控器插件” |
| 关机 | “关机”“关闭系统”“关闭盒子”“把盒子关掉” |
| 重启系统 | “重启”“重启系统”“重新启动盒子” |
| 挂起 | “挂起”“睡眠”“待机”“让盒子进入睡眠模式” |
| 返回安卓 | “重启到安卓”“切换到安卓”“返回安卓系统” |
