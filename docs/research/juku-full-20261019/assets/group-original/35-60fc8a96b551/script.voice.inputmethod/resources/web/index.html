申请豆包语音 API

前往豆包语音申请 API ↗
  1. 点击「立即使用」，登录火山引擎。
  2. 在顶部选择「新版体验」，进入「语音识别 → API 调用」。
  3. 创建 API，并开通「豆包流式语音识别模型 2.0」。
  4. 把 API Key 粘贴到下方，保存后点击测试。

新用户可领取 20 小时免费试用，具体额度、资格和有效期以控制台为准。按每天约 6–7 分钟估算，20 小时约为半年的使用量；这不是额度有效期承诺。

Key 保存在盒子的用户数据目录，权限 0600，不会离开本机。
