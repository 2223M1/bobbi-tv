⚡ 外部自动化脚本调用 API 说明

cURL / Python / Webhook / 网盘大包自动解析
当前目标媒体库: ID: lib_xxx 🔒 订阅媒体库为只读模式，仅支持选择自建媒体库
💡 网盘大包深度解析支持：支持直接传入 10 大网盘的根分享链接（无需提前解包或带 #fid=）。系统会自动深入递归扫描分享目录内部的视频文件，提取分集季集数、真实文件名及画质备注，并自动精准合并为电视剧或电影条目！
1. 接口基础规范
请求地址: POST http://127.0.0.1:17654/api/private/import_link
请求头: Content-Type: application/json
• 支持传入单个 JSON 对象 {...} 或 批量 JSON 数组 [{...}, {...}]
• 支持在 JSON 中直接保留 // 单行注释、/* */ 多行注释以及末尾逗号（内置智能容错清洗）
• 特大包自动异步防超时：若网盘大包包含的视频文件数 > 50，系统自动升级为后台异步导入并立即返回 task_id，杜绝客户端与反向代理 60s+ 超时断连；
• 进度轮询接口：通过 GET /api/private/import_task?task_id=xxx 实时查询任务匹配进度与最终入库结果。
2. 请求参数详解
参数名 类型 必填/可选 说明与示例
library_id string [必填] 目标私有媒体库 ID（上方下拉框可切换并一键复制）
url string [必填] 播放资源链接（支持 10 大网盘分享链接/大包、HTTP直链、磁力 magnet、ED2K 电驴）
imdb / imdb_id string [可选] IMDb 编号（如 tt7126948），通过 TMDB 100% 精确反查并刮削官方全套元数据
tmdb_id int [可选] TMDB 条目 ID（如 414906），直接精准刮削官方影视元数据与海报
vod_id / vod_info_id string [可选] 站方或自有影视 ID（若库内已有该 ID，直接合并追加链接）
title string [可选] 影视片名（若留空，后台自动从 URL 或文件名中智能提取并检索 TMDB）
year string/int [可选] 上映年份（如 2022，辅助片名精确对齐）
type_id int [可选] 影视分类：1 电影，2 电视剧/动漫/综艺
season / season_number int [可选] 季号（剧集使用，默认 1）
episode / episode_number int [可选] 集号（剧集使用，默认 1）
password / pwd string [可选] 网盘提取码/访问密码
remark string [可选] 资源清晰度/版本备注（如 4K REMUX 杜比视界）
skip_exists_link int/string [可选] 传 1 时检测媒体库中是否已存在以该链接开头的播放链接（包含大包展开后的 #fid=xxx），若已存在直接提示“该链接已导入，无需再次导入”，跳过重复扫描与入库
async bool [可选] 是否开启异步导入（true 时毫秒级返回 task_id；文件数 > 50 时即使未指定亦会自动开启）
