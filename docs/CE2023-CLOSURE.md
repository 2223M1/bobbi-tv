## CE2023 设备入口新增反例与 CE2024

CE2023 在真实 `default.py → bootstrap → Installer → KodiHost` 两次停在 switching。保存了 journal、Kodi 日志和 native stack；未覆盖原包。入口通过维护工具暂存，不冒充已经验收 Kodi ZIP 浏览器安装。

现场 GUI 线程等待 ScriptInvocationManager，安装线程等待 executebuiltin 的 SendMsg。核对 Kodi 21.3 实现：同步 executebuiltin 不释放 Python 锁；服务 Stop 需要获得该锁，而调用管理器锁同时被持有。这与两次现场栈一致。

CE2024 将 UpdateLocalAddons 改为异步 FIFO 完成标记，使用 Monitor 有限等待让出 Python 锁；标记未确认不得当作刷新成功。依赖安装同样异步提交，以实际版本回读完成。保留 journal、签名、恢复、回退和原有 15 秒等待范围。入口 0.2.15、platform 0.1.18；core/plugin 保留本轮 0.1.17/0.1.16。新增正常、失联、取消和迟到标记回归。首次旧夹具缺少真实 GUI 模型的失败保留，补充队列模型后 77 项通过。

CE2023 干净检出复验仍是 1818/789/177；不能拿它替代 CE2024 后续回执。设备恢复已通过原事务撤回第一次失败安装，账号和观看记录未操作。第二次反例也按原事务恢复，不手改 journal。
