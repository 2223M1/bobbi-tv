# 延续现有新 UI，不另起视觉风格

依据已审查基线 `a9189b5d157d886c814cf28c6748c97fc6825a35` 的新影院配色与组件，
不是早期废弃皮肤。新增安装、登录、连接、失败恢复页面共用这些规则：

- 背景 `#0A0B0E`，卡片 `#15171C`，浮起层 `#1E2128`，边线 `#2A2E37`。
- 正文暖白 `#F5F3EF`，次要文字 `#B4B2AD`；橙色 `#FF8A3D` 只作少量强调。
- 遥控焦点为白底深字，圆角卡片，视觉层级为品牌、主标题、简短说明、主要动作。
- 焦点缩放 1.02，140 毫秒 ease-out；焦点变化先取消上次动画，遵循系统关闭动效设置。
- 不使用重复闪烁、长时间飞入、无意义循环动画。错误使用同一卡片结构，不突然切成开发者控制台。
- 字体换成未修改、随软件可再分发的 HarmonyOS Sans SC；保留许可证和显著声明。
  Kodi 键盘图标用 Font Awesome Free 6.7.2 的近似字形，保留 OFL，不含 Pro 字体。
- 不增加与原影院不一致的渐变配色、拟物图案或另一套图标美术。

Android 助手已应用同一配色、双栏/窄屏纵向布局、卡片、字体、焦点和动效。
Kodi 首次设置使用现有皮肤的标准选择框与对话框，因此继承当前皮肤而非独立主题。
系统安装确认、权限授权、文件选择器属于 Android 系统 UI，不能保证与影院完全同样。

静态测试验证共享配色、原字库哈希及焦点参数；**尚未在电视截图核验排版和动效**。
