# 本地阶段记录 · 2026-10-19

## 最新决定

- `bobbi` 统一命名；同一库仅 CoreELEC 版和通用 Android APK 版，不让用户选型号。
- 不做 Zidoo 专用适配，不把 Zidoo 联通当通用 Android 开发前置条件。
- 原生 Android 首测以后用 AM6B Plus；用户现在不方便协助，所以本轮不重启、不改盒子。
- 停止子代理，后续本轮由主代理独立完成。
- 新增页面必须沿用现有新 UI 的美术和审美；不改变现用 CE 的皮肤。
- 已授权公开清洁目录、分享链接与提取码；未授权公开登录 Cookie、账号密码或私人备份。
- 无原字体再分发授权，已改相近的可再分发字体，保留独立许可证和署名。

## 本轮已落实

- Android 通用 ARM32/ARM64 助手含真实 TorrServer 引擎，不是空壳声明。
- 新增 CinemaStyle：现有影院同源配色、HarmonyOS 原字库、圆角卡片、白色焦点、
  140ms/1.02 焦点动效并遵守系统关闭动画；宽屏双栏、窄屏纵向，不检测品牌型号。
- 原 Pro 键盘图标替换为 Free 6.7.2 的相近真实字形，逐个检查 cmap，完整 OFL 随包。
- Kodi 向导改成中文分步菜单；可导入助手配对文件，真实检查401/授权200/版本后才保存，
  失败或取消保留原配对，返回不中断其它播放，不把诊断通过说成播放通过。
- 通用选源接入本机 BT：核对全部提供的 magnet 与 infohash；一次添加；最多30秒网络预算；
  明确手选具体文件后一次交给 Kodi，不猜首文件、不冒充目录季集证据、不自动换版本。
- 皮肤/插件版本依赖统一0.1.0；迁移候选移除旧 bencodepy，改用现有 MIT flatbencode。

## 个人网盘 / NAS / 片库补充

- 新增 `plugin.video.bobbi.library`，本机/U盘、SMB、NFS、WebDAV 与用户直链 JSON 统一管理。
- 使用 Kodi 原生 VFS，不启动额外文件服务、不扫描局域网、不读取私人 NAS 凭据。
- 原生对话框支持添加、检查、修改账号/路径、更新片库、确认移除；移除不改动远端媒体。
- SQLite 独立保存当前 profile 的来源，凭据不进入插件路由；旧单目录仅迁移一次，删除后不复活。
- 路由只含来源 ID 和相对条目；拒绝越界路径、STRM、脚本、插件命令；分页覆盖完整10000项上限。
- 用户点中具体文件才一次交给 Kodi；取消、新请求、来源被修改/移除后不提交旧内容。
  提交回执未知不重试，不全局 Stop、不切源、不转码。
- 新 UI 顶部“我的”实际引用的是 `maintainable_ui.entries('am6b_home')`；在此增加两项，
  不改废弃 `IncludesCinema.xml`、不覆盖原入口、不另造主题。
- OpenList/AList/CloudDrive 只通过其已有标准目录接入；不是所有网盘原生登录，
  不是 Emby/Jellyfin/Plex 专用客户端，不自动将文件名猜成影视身份混入搜索。
- 新增98项回归测试，涵盖记录持久化、损坏数据、凭据编码、用户取消、更新失败保留原记录、
  分页完整性、只读检查、源删除与过期请求、播放单次交接和未知回执。
- [接入说明](LIBRARIES.md)记录网络/权限/超时边界；未连接真实 NAS、未部署到盒子。
- Android 代码/APK 此次未变；NAS 功能在 Kodi 组件，不能宣传为助手已包含完整影院。
