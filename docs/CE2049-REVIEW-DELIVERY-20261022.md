| 故障 | 旧行为 | 本轮结果 |

| 已撤销分享重新推荐 | QQdocs 成功缓存和 Juku 快照重新发出普通候选 | 在原目录 SQLite 中追加账号代际＋精确文件 tuple 的有界失败记录；最多 1024 条、6 小时；失败卡保留并标记，可手动重试，不推荐、不遮蔽 BT；新成功压过旧迟到失败；网络/超时/登录/取消不记作撤销 |

| 外壳不绑定签名入口 | 修改 default.py、XML 或新增成员仍通过 audit | 所有外层入口成员及字节必须等于签名入口＋同代 bootstrap＋完整载荷；实际 CE2049 包 5 种临时变异均拒绝，变异包未执行 |

旧 schema=1 正常终态 journal 可继续升级；没有旧程序收据时，不对现场未知字节临时补造证明，也不执行破坏性回退。已有中间 restore_pending/旧 boot-gate 兼容仍保留。账号、观看数据与第三方插件不纳入程序恢复向量。

本轮全量回归还发现并修复了设置页的临时模块装载缺口：新 IO 组件改为随 backend 一同载入，命名空间仍完整清理，现有 BT 设置页继续只做 echo 检查。

## 真实观看限制

新作品选用《心灵驿站》（TMDb 2056）与《日常》（TMDb 44684），此前项目验收记录没有这两部。测试工具先核验 TMDb 标题、年份、类型；《日常》最初测试夹具使用了错误 ID，已被入口拒绝，随后通过真实 API 查询纠正，不能记作产品目录失败。

《心灵驿站》首轮热更新会话没有进入 AV。重启后的同一 1080p AMZN NTb 源约 **4.09 秒进入 AV**，英文原声、外挂中文字幕应用回执已到，解码器丢帧/硬件错误为 0。但约 **36 秒进入持续缓存**，后续 30 秒播放时间未推进，严格实播失败。停播后同 hash 查询为 404；这不能单独证明停播前断供根因。没有降低画质、改解码或用另一低码率版本刷通过。两次字幕平面截图没有可见对白，不冒充中文字幕视觉/同步验收。

《日常》S01E01 选择 7³ACG 1080p HEVC/OPUS。第一轮停留在人工文件框超过约 60 秒后取消，原结果保留；第二轮查询的同组卡片来自不同检索条目，旧稳定键选择被测试工具拒绝，读取新卡后重新手选。确认明确的 S01E01 文件后，种子没有因长停留丢失，进入正常 preload；记录到 23.4/32.2 MB、约 413 KB/s，随后进入 AV，内嵌 `chi / chs[FLsnow]` 已启用、1080p HEVC 硬件解码无丢帧/错误。含人工停留与缓冲的总启动观察约 154.6 秒，不能描述为快速开播或完整整集通过。本轮不因源码测试通过而宣布所有观看问题已解决。

仍未验收：长时间弱 BT、完整中途 BT→115 交接、当前代次准确同版自然 EOF 续播、新影片的实际字幕字形/同步、其他 CE 硬件和冷安装。上轮像素测试仍保留 INCONCLUSIVE，不恢复“绝对无闪动通过”的说法。

《日常》后续 30.349 秒观察中，播放推进 30.28 秒，当前采样无缓存，累计至约 89.6 秒，解码丢帧/错误均为 0；此短时观察通过。GUI/字幕平面截图仍未捕捉到可见对白，因此不声称字体裁切或同步已得到本轮视觉认证。两部作品均使用实例绑定的停止操作收尾，最终 CE2049 为 complete、无 host_pending、皮肤 `skin.bobbi.cinema`，Kodi active / NRestarts=0，BT 后台仍为 3647。

另做旧故障回归《星空清理者》S01E01（不计作新作品）：实际选取同一 `Planetes.2003.S01E01.1080p.BDRip.x265.FLAC-CoolFansSub.mkv`，播放仍被上游拒绝。关闭播放失败提示后，另一次普通查询中的同一稳定键 `c0466146…` 显示“分享已失效 · 可手动重试”，推荐标记为空，BT 候选仍在；旧查询中该卡曾为“推荐”。这是失效状态跨查询保留的真实设备证据，不是修复了上游已撤销分享，也不算该片播放成功。原测试 attempt 2 已存在，入口拒绝覆盖；本轮另用 10 和 9，原件均保留。

## 安装与恢复说明

从本次测试预发布下载 `script.bobbi.start-CE2049.zip`，保持 ZIP，在 Kodi“从 ZIP 文件安装”安装，打开“波比 TV · 开始使用”选择入口内附完整包。安装后重启 Kodi；进入影院并确认“保持皮肤？”。不包含任何登录状态或签名私钥。

停止播放后可使用入口的程序回退。坏备份会明确拒绝，不要求 SSH 改 journal；请保留备份。旧安装器无收据时只能继续用更新的完整包恢复，不冒险拼接旧代次。不要重放 CE2048/旧序列来绕过高水位。
