## 已落实的窄修

- 安装恢复：现代服务和未知状态必须先取得真实 OS lease 再禁用插件；只有完整的旧协议状态回执保留 legacy stop 路径。跨对象、实际 apply 异常重入与 recover 均覆盖，不扩大 15 秒预算、不强杀。
- HistoryWriter：诊断出口异常不杀死存储线程；统计 accepted/completed/failed/diagnostic_failures，意外退出或未排空不能成功 close。
- ShareStream：服务登记所有已接纳 producer。handler 的 15 秒 join 不再等于服务排空；最终 close 等待真实上游 IO 退出，不持工作线程退出所需的锁。失败可重试，关闭后不接纳新任务。
- 字幕：拒绝单文件的逗号、顿号、分号等多集枚举；逐元数据字段解析中文/序数季号及特别篇反证，去除规范片名后判断。保留明确同季包、可信单季 EP01/第01話/[01] 正控，不改视频续播语法。
- 测试回执 schema 2：分离 recorder 与 execution，记录两者执行前后 Git 顶层、commit/tree/status；无 Git 不回退到 recorder。新验收门禁拒绝未知、dirty、变更中执行及旧 schema。不重写历史回执。
- 解码诊断 schema 2：保留各 channel/device/counters、原文哈希和读取时间；同播放实例、同通道且无 reset 才计算增量。不将 DV 双层帧数相加，不把累计错误归入后续短观察窗。

## 本轮独立发现：试播身份错误

上轮工具将《比宇宙更遥远的地方》的 TMDb ID 写为 76013。实际设备缓存和实时 TMDb 都表明该 ID 是英语节目 **NFL Football Fanatic**，并非这部日本动画。正确 ID 是 **76059**，原语言 ja，首播 2018-01-02。

因此上轮英语原声和字幕未匹配不能直接归因于产品原声/字幕机制；之前的缓存语言 en-US 也不是“英语配音”的证据。保留全部旧回执并标为错误测试身份。BT 48.496 秒准备、46.401 秒 buffering 是该实际请求的真实记录，不能由身份修正消除。

工具新增真正起播前的元数据核对：ID、规范片名、年份和已声明的动画类型。失败先停在测试入口，不修改 GUI、不自动猜另一个 ID。新旧请求分开记账，使用正确 ID 同片源重测。
