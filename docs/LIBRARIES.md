# 接入自己的网盘、NAS 与片库

这是公开版 Kodi 组件当前已实现的预览功能，**尚未完成实际 NAS / Android 设备验收**。
CoreELEC 与 Android/Kodi 共用同一实现，不要求选择 NAS 品牌或盒子型号。
Android 助手 APK 负责 BT 后台与配对；个人片库功能在 Kodi 组件中，不能只安装助手代替影院。

## 从哪里进入

- 新 UI 移植候选：顶部「我的」→「我的网盘 / NAS / 个人片库」，或「添加与管理我的来源」。
- 不依赖皮肤的预览入口：「视频插件」→「bobbi 我的片库」→「管理网盘 / NAS / 片库」。
- 首次向导：「程序插件」→「bobbi 首次设置」→「我的网盘 / NAS / 片库」。

新入口使用现有新 UI 的菜单行、白色焦点和原生对话框，不新增另一套主题。
已存连接可多次进入继续配置；向导显示的是“已保存”，不冒称设备在线。

## NAS：推荐家庭网络先用 SMB

1. 在 NAS 开启 SMB 共享，给自己的账号授予目标目录读取权限。
2. 盒子与 NAS 处于能够互通的家庭网络；访客 Wi-Fi、隔离 VLAN 和双路由可能互不通。
3. 点「添加来源」→「NAS / 网络共享（SMB）」。
4. 填写 `nas.local/Movies` 或 `smb://NAS地址/共享名`，起一个名称，再输入账号和密码。
5. 确认保存后点「检查连接」，然后返回「我的片库」选文件播放。

使用 NAS 已启用的 SMB2/SMB3 与 Kodi 默认兼容设置；不建议为了连通降低到 SMB1。
NFS 用户选择「NAS（NFS）」并填写 `nfs://NAS地址/导出路径`；访问权限由 NAS 的导出规则决定，
此方式不询问账号密码。Kodi 已保存的网络目录也可以直接通过文件选择器添加。

密码输入隐藏；修改连接时可保留原账号密码、重新填写或改用匿名访问。
连接检查只读取当前一层目录，不递归扫描 NAS，不下载视频，更不是自动试播。
空目录、权限不足或没有视频不会被显示成“播放已验证”。

## 其他网盘：WebDAV 或已有挂载

选择「网盘 / NAS（WebDAV）」，填写服务提供的 WebDAV 根目录和自己的账号密码。
例如 `https://nas.example:5006/Movies/`，程序自动转成 Kodi 的 `davs://`；HTTP 对应 `dav://`，
保存前会提示明文传输。家庭外访问优先使用 HTTPS，不会自动开放公网端口或改路由器。

已有 OpenList/AList 的 WebDAV 服务可直接填入地址；已通过 CloudDrive 等挂载的网盘，
使用该工具实际提供的本地目录、SMB/NFS 或 WebDAV 地址。bobbi 不要求把网盘搬到作者服务器。
若云盘本身没有标准目录服务，仍需要先由对应工具完成账号登录与挂载。

当前不包含所有品牌的原生扫码登录，也不实现 Emby、Jellyfin、Plex 专用 API。
这些服务背后的媒体若已有 SMB/NFS/WebDAV 共享，可按上述步骤接入，但不会同步其观看记录。

## 本机 / U盘

选择「本机、U盘或 Kodi 已保存的网络目录」，用文件选择器选择媒体目录并命名。
只访问 Kodi 在当前系统已获准读取的位置，不请求 root 或绕过 Android 存储权限。
移走 U盘或改变挂载位置后，可在来源管理中修改目录，不必重装影院。

## 自有直链片库（可选高级功能）

NAS 用户不需要编辑 JSON。已有 HTTP(S) 视频直链清单的用户可导入以下 UTF-8 文件：

```json
{
  "schema": "bobbi-library-v1",
  "name": "我的电影",
  "items": [
    {
      "id": "film-001",
      "title": "示例电影",
      "year": 2024,
      "url": "https://media.example/movie.mkv"
    }
  ]
}
```

`year` 可省略；每项 `id` 唯一。每份最多 2 MB、2000 项，本机最多 32 个来源。
不接受插件命令、脚本、STRM、带账号密码的 URL 或自定义请求头；签名直链到期后需更新片库文件。
「更新导入的片库」会先完整检查新文件；失败或取消保留旧清单，成功后仍使用原来源标识。
导入仅保存本地条目，不批量探测 URL、不创建云任务、不抓取或下载另一版本视频。

## 播放与维护边界

- 所有来源统一显示在「我的片库」，逐层浏览，每页 200 项；单层超过 10000 项请指定更小的子目录。
- 用户明确点中具体文件后才交给 Kodi；不自动播放首个文件、不换版本、不转码或降低分辨率。
- 这是目录浏览，不会把文件名自动识别为 TMDb 作品或混入影视搜索，以免错误合并年份、季集和剪辑版。
- 内嵌/同目录字幕、音轨、ISO 解码能力沿用 Kodi 与设备支持；未宣称完成公开版的自动字幕与续播移植。
- 移除来源只删除 bobbi 本机连接/导入清单，NAS、网盘、文件和 Kodi 原有 sources.xml/passwords.xml 均不改。
- 账号保存在当前 Kodi profile 的本地 SQLite 中，不随发行包或同步上传；**不是加密保险库**。
  插件路由和本插件错误信息不携带账号，Kodi 自身调试日志仍可能记录完整媒体 URL；不要公开原始 profile 或带账号的日志。
- 目录访问由 Kodi 原生 VFS 完成，等待时间受 NAS、网络和 Kodi 控制；此预览没有额外实现可强制中断的网络驱动。
  检查失败时先核对共享路径、账号权限和网络隔离，不以反复重装处理。具体断网等待体验待实机验收。

本轮只有本地自动化验证和预览包构建，没有连接用户实际 NAS、切换盒子系统或覆盖私人影院。
